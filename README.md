
# Tu Catálogo Web

¡Felicidades! Has exportado tu catálogo de productos como un sitio web estático.
Sigue estos sencillos pasos para publicarlo gratis en internet usando GitHub Pages.

## Cómo publicarlo

### 1. Descomprime el archivo
Descomprime el archivo `catalogo-web.zip` que acabas de descargar. Encontrarás los archivos `index.html`, `data.json` y este mismo `README.md`.

**Nota importante sobre las imágenes:** Para hacer el proceso más simple, todas las imágenes de tus productos y tu logo **ya han sido convertidas e incluidas directamente dentro del archivo `data.json`**. Esto significa que no necesitas subir ninguna carpeta de imágenes por separado. ¡Solo con los archivos `index.html` y `data.json` tu catálogo estará completo!

### 2. Crea un repositorio en GitHub
- Ve a [GitHub](https://github.com) e inicia sesión.
- Haz clic en el signo **+** en la esquina superior derecha y selecciona **"New repository"**.
- Dale un nombre a tu repositorio (por ejemplo, `mi-catalogo`).
- Asegúrate de que sea **Público**.
- No necesitas añadir un `README`, `.gitignore` o licencia al crearlo.
- Haz clic en **"Create repository"**.

### 3. Sube los archivos
- En la página de tu nuevo repositorio, haz clic en el enlace **"uploading an existing file"**.
- Arrastra los archivos `index.html` y `data.json` a la ventana del navegador.
- Haz clic en **"Commit changes"**.

### 4. Activa GitHub Pages
- En tu repositorio, ve a la pestaña **"Settings"**.
- En el menú de la izquierda, haz clic en **"Pages"**.
- En la sección "Build and deployment", bajo "Source", selecciona **"Deploy from a branch"**.
- Asegúrate de que sea `main` y la carpeta sea `/ (root)`.
- Haz clic en **"Save"**.

### 5. ¡Listo!
GitHub tardará uno o dos minutos en construir y desplegar tu sitio. En la misma sección de "Pages", verás un mensaje con la URL de tu catálogo en vivo (algo como `https://tu-usuario.github.io/mi-catalogo/`).

¡Ya puedes compartir esa URL con quien quieras!
