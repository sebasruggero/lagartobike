
# Tu Catálogo Web

¡Felicidades! Has exportado tu catálogo de productos.

## Instrucciones
1. Descomprime el archivo ZIP.
2. Haz doble clic en `index.html` para verlo en tu navegador.
3. ¡Listo! No necesitas internet ni servidores, funciona 100% offline y puedes enviarlo por USB, email o subirlo a GitHub Pages.
